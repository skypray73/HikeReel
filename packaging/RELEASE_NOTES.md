## HikeReel v2.1.3（2026/10/25）

### 3D 跟隨鏡頭：角度調高，加入緩慢的視角變化

- v2.1.2 的低空視角太貼近地面，這版把跟隨高度調回中間值（高度／距離比 0.28，約 11°～20°），視線改為微俯 5°：小人、腳下地形與前方山稜天際線同時入鏡。
- 新增視角變化：鏡頭會依走過的路程，在小人身後**左右繞行最多約 25°**，高度也一起緩慢起伏（約 16 秒一輪，兩種週期疊加，不會像鐘擺來回）。停下看照片時鏡頭跟著靜止。
- 避山、拉近、保留小人在高度剖面上方等防護都納入新的繞行方向一起計算。
- 進階使用者：`--orbit` 設定繞行角度（預設 25，`0` 為固定在正後方且不起伏），`--pitch` 預設 0.28，`--look-up` 預設 -5。

### 下載與使用

下載 `HikeReel_v2.1.3_Windows.zip`，整個解壓縮後執行 `HikeReel.exe`；保留 `_internal` 資料夾。

3D 需要自己的 ArcGIS Location Platform API 金鑰（Esri 影像）；2D 免金鑰。請保留影片的圖資來源標示。程式碼採 MIT License，完整使用方式與授權見 README。
