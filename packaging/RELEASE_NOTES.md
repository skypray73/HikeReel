## HikeReel v2.2.0（2026/10/25）

### 3D 製作速度大幅提升，充分利用顯示卡與多核心 CPU

- **修正 RTX 50 系列（5070 / 5080 / 5090）無法使用 NVENC 硬體編碼**：舊版用太小的測試畫面偵測 NVENC，新世代顯示卡會拒絕，結果一律退回 CPU 編碼。2D、3D 模式都受影響，這版已修正。
- **製作時切到其他視窗不再變慢**：Windows 會把不在前景的程式當成背景工作，改用省電核心並降頻，速度可能掉到 1/5 以下。HikeReel 現在會關閉這項節流（主程式、疊圖行程與 ffmpeg）。
- **疊圖平行處理**：儀表板、地標標籤、大氣霧化分散到多個 CPU 行程，透過共享記憶體交換畫面，與顯示卡渲染下一幀同時進行。
- **儀表板只畫會變的部分**：面板、格線、刻度等固定內容只畫一次，每幀只更新數字與目前位置；畫面與舊版逐像素相同。
- 實測（i7-12700F + RTX 5070，1080p、含地標）：v2.1.3 每秒約 5–16 幀且忽快忽慢，v2.2.0 穩定約 25–30 幀。

### 其他

- 新增「檢測硬體與顯示卡加速」：顯示 CPU、顯示卡型號、驅動與顯示記憶體，以及 3D 渲染是否在獨立顯示卡上、影片是否用 NVENC 編碼。
- 橫式影片左下角的儀表板縮小到約原本的 2/3 寬（畫面寬度 22%），主畫面更寬敞。
- 顯示卡使用率在工作管理員裡偏低是正常的：每幀 3D 渲染只要幾毫秒，1080p 約只用 1 GB 以內的顯示記憶體，不會因記憶體不足而降速。

### 下載與使用

下載 `HikeReel_v2.2.0_Windows.zip`，整個解壓縮後執行 `HikeReel.exe`；保留 `_internal` 資料夾。

3D 需要自己的 ArcGIS Location Platform API 金鑰（Esri 影像）；2D 免金鑰。請保留影片的圖資來源標示。程式碼採 MIT License，完整使用方式與授權見 README。
