## HikeReel v2.1.2（2026/10/25）

### 3D 鏡頭改成後上方低空跟隨、微仰視山景

- 降低跟隨高度，視線預設向上 3°，讓前方群山、山稜與天空入鏡，不再一直低頭看路線。
- 後方山坡擋住時先平順拉近鏡頭，減少為了避山而升得太高的情況；必要時仍會升高並調低仰角，保留畫面下半部的登山小人。
- 避擋判斷改用真正的移動點位置，避免平滑路線切入山坡時，把鏡頭不必要地抬高。
- 配合新角度調整直式照片停留構圖，讓小人較不容易被底部高度剖面蓋住。
- 開場與抵達終點後的路線總覽仍保留；轉向平滑與地形穿透防護持續生效。
- 跟隨高度與避山動作依路程平滑，減少短片提前升到遠方山坡高度的俯瞰感；小人尺寸也配合近距離鏡頭調整。
- 進階使用者可用 `--look-up` 指定仰角（預設 3；0 為平視、負值為俯視），`--pitch` 指定高度／距離比（預設 0.10）。GUI 直接使用新山景視角。

### 下載與使用

下載 `HikeReel_v2.1.2_Windows.zip`，整個解壓縮後執行 `HikeReel.exe`；保留 `_internal` 資料夾。

選擇 3D 模式、加入 GPX 後即可使用新鏡頭。3D 需要自己的 ArcGIS Location Platform API 金鑰；2D 免金鑰。

GPS 照片自動配對、500 公尺預設半徑、選填影片標題與舊照片清單皆可繼續使用。請保留影片的圖資來源標示。程式碼採 MIT License，完整使用方式與授權見 README。
