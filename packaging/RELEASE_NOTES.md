## HikeReel v2.1.0（2026/10/25）

### 照片 GPS 自動配對

- 新增「📍 匯入 GPS 照片…」：一次選多張照片，自動讀取 EXIF GPS，安排在軌跡最近的位置顯示，不需要先建立 Excel 地標。
- 匯入視窗可切換 GPX 預覽，顯示照片經緯度、離軌跡距離與是否會出現；也能修改卡片名稱、手動補上／修正座標、移除項目。
- 沒有 GPS 的照片明確提示，未補座標就略過，不推測位置；相同內容重複匯入不新增，同位置多張照片會依序播放。
- 2D 與 3D 都能使用 GPS 照片，可與 Excel 地標照片一起呈現；每張停留秒數共用原有設定。
- Windows 執行檔包含 HEIC／HEIF 解碼器，支援手機原始照片。

### 配對距離與修正

- 預設沿用 **0.5 km（500 公尺）**，主視窗可調整「地標／照片半徑(km)」。照片定位偏差較小時可用 0.1～0.2 km，避免混入其他行程。
- 從「最近 GPX 取樣點」改為「最近軌跡線段」，點位較疏也能找到中間路段；修正舊版經度邊界框在較高緯度可能漏選地標的問題。
- 到達最近的路線位置才顯示照片，不是一進 500 m 就播放。平面距離不比較高度；折返／交叉路段同樣接近時採第一個最近位置，不以拍攝時間判斷。
- 修正 2D 批次產片可能沿用上一條路線地標的狀態；每條 GPX 會獨立篩選照片。

### 下載與使用

下載 `HikeReel_v2.1.0_Windows.zip`，整個解壓縮，執行 `HikeReel.exe`；保留 `_internal` 資料夾。

1. 加入 GPX，選 2D 或 3D。
2. 按「📍 匯入 GPS 照片…」→「＋ 匯入照片」。
3. 查看離軌跡距離；無 GPS 的照片先補座標。
4. 調整篩選半徑與每張停留秒數，開始產片。

照片複本與 GPS 清單在所選照片資料夾的 `gps_imports/`、`gps_photos.json`；原始照片不修改，HikeReel 不會上傳照片或定位。重新開啟後選同一照片資料夾即可沿用。

3D 需要自己的 ArcGIS Location Platform API 金鑰；2D 免金鑰。FFmpeg 選用，可由程式下載 SHA-256 驗證的官方來源建置。影片請保留地圖來源標示，完整授權見 README 與程式內說明。
