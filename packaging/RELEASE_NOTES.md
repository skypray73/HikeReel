## HikeReel v2.1.1（2026/10/25）

### 修正 GPS 照片顯示檔名

- GPS 照片預設**只顯示照片，不顯示檔名或標題列**，避免 `IMG_1234` 這類名稱出現在影片中。
- 匯入清單新增「影片標題（選填）」欄及「設定影片標題」按鈕。自行填寫說明才會顯示，例如「三尖峰北壁」；清空後確定即可隱藏標題列。
- 清單內的照片名稱僅供辨識，不會自動帶入影片。Excel 地標照片仍顯示原有地標名稱。
- 相容 v2.1.0 的照片清單；舊照片預設也隱藏檔名，不需要重新匯入。若先前改過清單名稱作為說明，請用新版「設定影片標題」填入要顯示的文字。
- 2D／3D 共用此設定；GPS 距離配對、500 公尺預設半徑與每張停留秒數維持原有操作方式。

### 下載與使用

下載 `HikeReel_v2.1.1_Windows.zip`，整個解壓縮，執行 `HikeReel.exe`；保留 `_internal` 資料夾。

1. 加入 GPX，按「匯入 GPS 照片…」選取照片。
2. 預設不必填標題；照片會在最近的路線位置顯示。
3. 需要說明時選取照片，按「設定影片標題」；留空並確定則恢復無標題。

v2.1 的 EXIF GPS 批次匯入、無 GPS 手動補座標、距離預覽及 HEIC／HEIF 支援皆保留。照片與座標只在本機處理；若沿用舊資料，請在主視窗選擇原本包含 `gps_photos.json` 的照片資料夾。

3D 需要自己的 ArcGIS Location Platform API 金鑰；2D 免金鑰。請保留影片地圖來源標示。程式碼採 MIT License，完整授權與使用方式見 README。
